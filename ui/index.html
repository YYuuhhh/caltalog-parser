Catalog details

Catalog IDs are automatic: manufacturer + PDF fingerprint. They connect source pages, caches, review evidence and library records. Revision distinguishes editions; languages guide interpretation; families select the tool schemas.

Extraction quality & limits

Automatic quality measures native-text coverage and available OCR text confidence. Low-confidence pages retry with OCR or native text. It keeps the stronger result without losing table cells. These diagnostic scores do not replace model review.

Local models · memory & server

CPU only · one task and one loaded model at a time. Presets reserve RAM for context, images, the extractor and the operating system. Models are never downloaded by merely selecting them. Open either model menu to see installed models, install missing weights and follow download progress on the selected server. Missing web evidence leaves internet checks unverified.

Review context & image quality

Each request has a fixed goal and the stage's chosen reasoning. Context is limited to one page and a bounded group of records or tools. Sessions are never resumed. Original page images accompany every task.

Mapping rules & editing

A rule connects a printed header to a structured field. Family and series limits prevent the same letter being given the wrong meaning. Unverified proposals stay visible for review. Saving makes a versioned manufacturer profile; existing source files are preserved.

06

Final tool validation

An independently selected model checks structured tools against their original evidence.

Independent model

  • Correct letters, parameter meanings and series-specific mappings
  • Every value, unit, fit, tolerance and dimensioned drawing
  • Original PDF and precise official internet sources
  • Duplicate candidates and conflicting parameter values
  • Workbook integrity and catalog completeness

A missing review, incomplete catalog, unavailable source or unresolved value prevents validated status. Review issues remain attached to the catalog.
